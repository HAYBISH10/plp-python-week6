# Assignment: Times Tables, Skip Counting & Loop Hospital

This assignment practices Python `range()`, `for` loops, loop steps, f-strings, and debugging common loop errors.

## Files

* `times_table.py` - Generates a multiplication table from 1 to 10 for a number entered by the user.
* `skip_counter.py` - Uses `range()` with positive and negative steps to print even numbers and a countdown.
* `loop_hospital.py` - Fixes three common loop bugs involving off-by-one errors, infinite loops, and misplaced accumulators.
* `screenshots/` - Contains screenshots showing the required program outputs.

## Off-by-One Errors

An off-by-one error happens when a loop runs one time too many or one time too few because the starting or ending value is incorrect. A useful `range()` habit is remembering that the stop value is not included, so I carefully check the start and stop values before running my program.
